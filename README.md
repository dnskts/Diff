# Сравнение файлов

Локальный сервис: два файла с диска пользователя, отличия по значениям, живая полоса прогресса и Excel-отчёт. Интернет на сервере не нужен.

Код рассчитан на **PHP 7.4+** (в том числе PHP 8). Зависимости уже лежат в `vendor/` и ставятся только на машине разработчика.

## Запуск

```bat
serve.bat
```

Или вручную из корня проекта:

```bat
php -S 127.0.0.1:8080 -t public
```

Откройте http://127.0.0.1:8080

Для Apache/Nginx document root — каталог `public/`. Каталоги `src`, `vendor`, `storage` снаружи корня сайта.

## Форматы

| Модуль | Файлы |
| --- | --- |
| `src/Modules/Table/CsvModule.php` | CSV, TSV |
| `src/Modules/Table/XlsxModule.php` | XLSX, XLSM, бинарный XLS |
| `src/Modules/Table/HtmlExcelModule.php` | HTML и «Excel из HTML» |
| `src/Modules/Text/TxtModule.php` | TXT |
| `src/Modules/Text/DocxModule.php` | DOCX (ZIP + document.xml, без PhpWord) |
| `src/Modules/Text/DocModule.php` | DOC, best-effort без OLE/PhpWord |

Новый формат — отдельный класс и строка в `Diff\App::modules()`. Таблицу с текстом сравнивать нельзя.

## Числа Excel

Сравнение идёт по канону, не по «как нарисовано в ячейке»:

- `1`, `1.0`, `1,0` — одно значение
- хвост float вроде `1.0000000002` схлопывается (10 знаков)
- процент в Excel (`0.15` с форматом `%`) равен строке `15%` — канон `0.15`
- даты приводятся к `Y-m-d` или `Y-m-d H:i:s`, а не к serial Excel
- коды с ведущими нулями (`00123`) остаются текстом и не равны числу `123`
- даты со слэшем читаются как день/месяц/год

## Как устроен прогресс

Файлы уходят multipart-загрузкой с компьютера пользователя. Дальше браузер запрашивает сравнение порциями (`api.php?action=process`). Зелёная полоса на всю ширину — доля обработанных строк. Отличия дописываются в таблицу по мере ответа. По завершении отчёт лежит в задании и скачивается кнопкой «Скачать отчёт».

Задания в `storage/jobs` удаляются через 48 часов. Идентификатор задания случайный.

## Лимиты

- файл до 50 МБ
- до 100 000 строк таблицы и 50 000 текстовых блоков
- на экране первые 500 отличий, полный список — в xlsx

В `php.ini` на сервере должны быть не меньше лимита загрузки:

```ini
upload_max_filesize = 50M
post_max_size = 110M
memory_limit = 512M
max_execution_time = 120
```

Нужны расширения: `zip`, `xml`, `gd`, `mbstring`, `dom`, `fileinfo`.

## Офлайн-поставка

Скопируйте всю папку проекта, включая `vendor/`. На закрытом сервере `composer install` не запускается.

`phpoffice/phpspreadsheet` зафиксирован на ветке 1.29, потому что более новые версии требуют PHP 8.1+. Это осознанный выбор ради PHP 7.4. Сервис предназначен для своего контура, не для приёма чужих файлов из интернета.

Проверка ядра:

```bat
php tests/run.php
```
