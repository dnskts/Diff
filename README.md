# Сравнение файлов

Локальный веб-сервис: загружаете два файла, смотрите отличия на экране, открываете HTML-отчёт и при необходимости скачиваете Excel.

Интернет на сервере **не нужен**. Подходит для закрытого контура.

Требования: **PHP 7.4+** (работает и на PHP 8). Расширения: `zip`, `xml`, `gd`, `mbstring`, `dom`, `fileinfo`.

---

## Быстрый старт

1. Убедитесь, что в PATH есть `php`.
2. В корне проекта запустите:

```bat
serve.bat
```

Или вручную:

```bat
php -S 127.0.0.1:8080 -t public
```

3. Откройте в браузере: http://127.0.0.1:8080

Для Apache/Nginx document root — папка `public/`. Папки `src`, `vendor`, `storage`, `config` должны лежать **рядом** с `public`, а не внутри неё.

---

## Как пользоваться

1. Выберите файл «Было» и файл «Стало» (или нажмите **Два файла** и выберите оба сразу — тогда вместо «Было»/«Стало» покажутся имена файлов).
2. Нажмите **Сравнить** — сервис определит тип (таблица или текст) и покажет параметры.
3. Справа настройте ключ (для таблиц) или опции текста и нажмите **Найти отличия**.
4. Отличия появятся в таблице слева. Кнопка **Отчёт** откроет HTML-предпросмотр; внутри него есть **Скачать** (xlsx).
5. **Новое сравнение** сбрасывает всё и возвращает к выбору файлов.

Таблицу с текстом сравнивать нельзя — оба файла должны быть одного типа.

### Кто за что отвечает (коротко)

| Часть | Роль |
| --- | --- |
| `public/` | То, что видит браузер |
| `src/Http` | Маршруты API |
| `src/Compare` | Основной сценарий сравнения |

| `src/Report` | «Как отдать отчёт» |

## Как сравниваются числа Excel

Сравнение идёт по **канону** (нормализованному значению), а не по тому, «как нарисовано в ячейке»:

- `1`, `1.0`, `1,0` — одно и то же
- хвост float вроде `1.0000000002` схлопывается (10 знаков)
- процент `0.15` с форматом `%` равен строке `15%` (канон `0.15`)
- даты → `Y-m-d` или `Y-m-d H:i:s`, а не serial Excel
- коды с ведущими нулями (`00123`) остаются текстом и **не** равны числу `123`
- даты со слэшем читаются как день/месяц/год

Опционально можно игнорировать «шум» научной записи Excel (`1,23E+11`).

## Как устроен прогресс

1. Браузер отправляет оба файла (`action=upload`).
2. Сервер готовит задание (`prepare`) и начинает сравнение порциями (`process`).
3. Полоса прогресса показывает долю обработанных строк; отличия дописываются в таблицу по мере ответа.
4. По завершении появляется **Отчёт** (HTML-предпросмотр + скачивание xlsx).

Задания лежат в `storage/jobs/` и удаляются примерно через 48 часов. ID задания случайный.

---

## Лимиты

- файл до **50 МБ**
- до **100 000** строк таблицы и **50 000** текстовых блоков
- на экране первые **500** отличий; полный список — в отчёте (xlsx / HTML)

В `php.ini` на сервере желательно не меньше:

```ini
upload_max_filesize = 50M
post_max_size = 110M
memory_limit = 512M
max_execution_time = 120
```

## Офлайн-поставка

Скопируйте всю папку проекта, **включая `vendor/`**. На закрытом сервере `composer install` не обязателен.

`phpoffice/phpspreadsheet` зафиксирован на **1.29**, потому что более новые версии требуют PHP 8.1+. Это сделано ради совместимости с PHP 7.4.

Сервис рассчитан на свой контур, не на приём чужих файлов из интернета.
